## 一句话定义

> **温暖但不甜腻，柔和但不幼态，毛玻璃但不炫技，文艺但不空泛**

Warm 的核心不是“把页面染成米黄色”，而是用 **奶杏底色 + 淡橙光感 + 雾绿/雾蓝平衡 + 半透明层次 + 呼吸留白 + 轻文学文案**，把页面做得像一件长期放在身边的个人物件。

它应该有生活感、有一点温度，但依然干净、克制、耐看。

## 最适合

- 个人主页
- 生活档案
- 旅行 / 照片页面
- 日记 / 年度计划 / 纪念页
- 自媒体介绍页
- 温柔版邮箱 / 账号档案
- 私人档案馆入口
- 轻量个人工具页
- 需要长期保存的单文件 HTML

如果是银行卡、财务、账号管理等高密度页面，并且“找信息速度”明显优先于氛围，默认更推荐 **Xiazhouqi Clear｜下周七·清透**；只有明确要 Warm 时才使用 Warm。

## 设计口诀

> **底色给温度，玻璃给空气，留白给呼吸，字重给层级，颜色只做轻声提醒**

## 当前版本

**v1.0.0 — 2026-08-16**

这一版把原本“下周七风格”中最稳定、最有辨识度的部分正式整理成独立规范：

- 奶杏 + 淡橙 + 雾绿 / 雾蓝背景体系
- 轻毛玻璃而不是重玻璃
- 暖棕而不是纯黑正文
- 大组呼吸、小组紧凑
- Header / Section / Card 三层透明度与模糊度
- 文案允许有轻文学感，但不能堆比喻
- 手机端不溢出、不拥挤
- 导航保持正常文档流，不做悬浮条
- 复制按钮小而淡，但触控必须稳定
- 单文件 HTML、本地可打开、无 CDN 优先
- 改风格默认不改用户数据
