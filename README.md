# Xiazhouqi Warm Skill

> **Xiazhouqi Warm｜下周七·暖杏** — a soft, calm, warm, glass-touched visual system for personal pages, lifestyle archives, travel pages, journals, account pages, and gentle utility interfaces.

[简体中文](./README.zh-CN.md) · [Full specification](./SKILL.md) · [AI handoff](./AI-HANDOFF.md) · [Changelog](./CHANGELOG.md)

Part of the **[Xiazhouqi](https://xiazhouqi7.com)** design system.

## One-line definition

**Warm, not sugary. Soft, not childish. Glassy, not flashy. Poetic, not vague.**

Xiazhouqi Warm uses a milk-apricot base, pale orange light, muted sage / mist-blue support colors, soft glass, layered whitespace, and restrained lyrical copy. It should feel lived-in and personal rather than decorative for decoration's sake.

## Core formula

**Warm ground · translucent structure · quiet hierarchy · soft accents · human copy**

## Best for

- personal homepage / profile
- lifestyle archive
- travel / photo pages
- journal / annual plan / memory pages
- email or account archive when a warmer emotional tone is wanted
- private archive entrances
- personal tools that should feel gentle rather than technical
- single-file HTML meant to be kept for a long time

For highly dense financial / account management pages where information speed matters more than atmosphere, prefer **Xiazhouqi Clear** unless Warm is explicitly requested.
