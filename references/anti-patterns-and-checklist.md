# Anti-patterns & Checklist

## Anti-patterns

禁止默认加入：

- 全屏米黄色
- 大面积纯橙
- 少女粉
- 马卡龙彩色卡片
- 玻璃铺满所有控件
- 黑色科技风
- 巨型悬浮导航
- 巨型圆角
- 所有内容卡片化
- 过度文艺散文
- 大量 Emoji
- 3D 卡片强倾斜
- 常驻粒子动画
- 强光标追踪
- 外部 CDN
- 核心正文 iframe / srcdoc
- 手机横向溢出
- 为了设计发明内容

## Checklist

- [ ] 温暖但不黄
- [ ] 柔和但不糊
- [ ] 淡橙是光，不是底色
- [ ] 有雾绿 / 雾蓝平衡
- [ ] 暖棕文字层级清楚
- [ ] Header / Section / Card 玻璃层级不同
- [ ] 玻璃失效仍可读
- [ ] 卡片数量合理
- [ ] 文案不堆比喻
- [ ] 导航不悬浮
- [ ] ≤6 个短分类优先一排
- [ ] 360–390px 无横向滚动
- [ ] 长字符串可换行
- [ ] 输入框不触发 iPhone 放大
- [ ] 复制按钮真实可点
- [ ] 图片自然暖，不重滤镜
- [ ] 改风格没有擅自改数据
- [ ] 没有旧 CSS patch 堆叠
- [ ] 页面不像网红模板
- [ ] 页面有“长期保存”的质感
