# Components & Navigation

## Page icon

40px 左右，16px 圆角，淡橙渐变即可。

一个页面通常只需要 1 个主图标。

## Section badge

允许柔和渐变，但面积要小。

用途：
- 分类
- 地区
- 平台
- 主题

不要把 badge 变成大按钮。

## Tags

10–11px，小、淡、低饱和。

## Navigation

默认正常文档流。

硬规则：
- 不 sticky
- 不 fixed
- 不做悬浮胶囊岛

≤6 个短分类时：
1. 先缩短标签
2. 再压缩 gap
3. 再调整 padding
4. 最后才横向滚动

## Buttons

主按钮可以比 Clear 稍柔和，但不要大面积高饱和橙。

辅助工具更轻。

## Copy

视觉 22–26px，实际 hit area（点击范围）尽量 36–44px。

装饰伪元素必须 `pointer-events:none`。
