# Layout & Spacing

## Container

- Desktop max width: 980–1080px
- Mobile page padding: 12–14px
- Desktop page padding: 20–24px

## Rhythm

- Header → Nav: 14–20px
- Nav → first Section: 16–22px
- Section → Section: 16–24px
- Section title → content: 10–14px
- Card gap: 10–14px
- Card padding: 13–16px
- Related row gap: 4–8px

## Columns

Mobile: single column.

Tablet / Desktop:
- 2 columns for medium cards
- 3 columns only for small, simple cards
- Do not force 4 columns

## Important rule

> Same thought close · Same group moderate · New semantic group clearly farther

Warm 的留白要像“呼吸”，不是大块空场。
