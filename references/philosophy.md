# Philosophy

## Warm 的本质

> Clean but not sterile. Soft but not cute. Layered but not busy. Personal but not decorative.

Xiazhouqi Warm 追求的是“长期看仍舒服”，而不是第一眼强烈。

## 四个判断

### 1. 温度来自什么

来自：

- 奶杏底色
- 暖棕文字
- 淡橙光感
- 少量生活化文案
- 柔和透明层次

不来自：

- 全页橙黄
- 粉色
- 可爱图标
- 过多 Emoji

### 2. 高级感来自什么

来自：

- 层级清楚
- 透明度克制
- 阴影扩散自然
- 留白有节奏
- 颜色饱和度低

不是来自“毛玻璃越多越高级”。

### 3. 生活感来自什么

来自内容本身、照片、真实记录和轻文案。

不要用大量装饰模拟“生活感”。

### 4. Warm 的呼吸

- 同一个念头 → 靠近
- 同一个分组 → 中等距离
- 新语义分区 → 明显拉开

大组呼吸，小组紧凑。
